# Security

Keep secrets outside the checkout. Do not attach personal configuration, browser profiles, databases, or raw logs to issues. Use the redacting privacy scanner before every push.

This assistant can operate a browser and local tools. Read the source and restrict tool capabilities before using it on sensitive systems. The web server is intended for loopback access only; no public tunnel is configured by this export.

Report sensitive findings privately through the repository owner's GitHub profile. Never put an exploit containing real credentials in a public issue.
